# korg-Moss
Trinity Moss-TRI to triton EXB-Moss Fixer.
hi everybody.
it is very simple project, but i think it is time saver for the owners of korg triton EXB-Moss, as you know there is a program it's name Alchemist for converting the trinity to triton including the moss board, but as Bank M in the trinity once converted to triton Bank F there are issues with the AMS it was annoying,
so i did not build every thing from scratch, i just fixed the AMS issues, but you still need Alchemist converter to do so.
1- you convert your trinity V3 to triton vis Alchemist.
2- then you use my program to convert the output of Alchemist file then you are done.
load it to your triton without spending hours fixing AMS one by one 
i hope it is something useful
